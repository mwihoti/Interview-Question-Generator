# Interview Question Generator

A small Next.js App Router application that takes a job title and returns configurable interview questions generated by Google Gemini (`gemini-2.5-flash`).

https://interview-question-generator-38e9.vercel.app/

## Architecture

- **Frontend** — a Next.js App Router page with a client form component.
- **Backend** — a Next.js route handler at `app/api/questions/route.js` that holds the API key as an env var and calls Gemini's structured-output JSON mode.

The key is never sent to the browser.

## Local development

You need Node.js 20+ and a [Gemini API key](https://ai.google.dev/).

```bash
npm install
echo "GEMINI_API_KEY=your_key_here" > .env.local
npm run dev
```

The app will be available at `http://localhost:3000`.

## Notes

- Job titles are capped at 120 characters on the server.
- The form supports seniority, focus, and question count controls.
- The API includes basic in-memory rate limiting, upstream timeout handling, and retry/backoff for Gemini requests.
- The model is asked for structured JSON, so parsing is more reliable.
